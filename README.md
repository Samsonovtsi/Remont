# Калькулятор ремонта

Калькулятор для риелтора с двумя режимами:

- **Быстрый** — площади стен, плитки и число электроточек оцениваются автоматически.
- **Точная по замерам** — риелтор вводит фактические площади и количества, после чего backend считает постатейную смету.

## Ключевое бизнес-правило

**Вознаграждение риелтора = 5% только от стоимости работ.**

В базу вознаграждения НЕ входят:
- материалы;
- доставка / разгрузка / вывоз мусора;
- НДС.

То есть:

```
agentReward = worksTotal × 0.05
```

Для пакетов **Стандарт** и **Комфорт** используется детальная сметная модель по предоставленным сметам.

Для **Минимального** и **Премиум** в исходных материалах нет достаточной постатейной разбивки работ и материалов, поэтому калькулятор показывает ориентировочную стоимость, но не рассчитывает точное вознаграждение риелтора.

## Поля точного режима

- черновая площадь стен;
- чистовая площадь стен;
- черновая площадь пола;
- чистовой пол;
- площадь плитки (стены + пол);
- площадь плитки на балконе/лоджии;
- площадь натяжного потолка;
- площадь демонтажа перегородок;
- количество светильников;
- количество розеток/выключателей;
- количество дверей;
- площадь тёплого пола;
- количество санузлов.

## Структура расчёта

1. Черновые работы.
2. Чистовые работы.
3. Электрика.
4. Дополнительные работы.
5. Черновые материалы.
6. Чистовые материалы.
7. Доставка = 10% от материалов.
8. НДС = 5%.
9. Итог для клиента.
10. Вознаграждение риелтора = 5% от блока **работы**.
