# Калькулятор ремонта

Веб-калькулятор для риелтора: основные характеристики объекта → предварительная смета → вознаграждение риелтора 5%.

## Что изменено в версии 2

Для пакетов **Стандарт** и **Комфорт** расчёт больше не является простым умножением площади на цену за м². Backend повторяет структуру загруженных рабочих смет:

1. черновые работы;
2. чистовые работы;
3. электрика;
4. дополнительные работы;
5. черновые материалы;
6. чистовые материалы;
7. доставка = 10% от материалов;
8. НДС = 5%;
9. вознаграждение риелтора = 5% от итоговой стоимости для клиента.

Использованы тарифы, встречающиеся в предоставленных сметах:
- электрика — 1 961 ₽/м²;
- материалы к черновым работам — коэффициент 0,55;
- материалы к чистовым работам — расчётный коэффициент 1,265;
- доставка/разгрузка/вывоз — 10% от материалов;
- дверь — 22 920 ₽ материал + 10 000 ₽ монтаж;
- потолочное полотно — 319 ₽/м²;
- светильник — 352,94 ₽ + 600 ₽ монтаж;
- розетка/выключатель — 518 ₽ + 500 ₽ монтаж;
- тёплый пол — 9 922,8 ₽ комплект на каждые 3 м² + 4 255 ₽/м² монтаж.

Площади стен, плитки и число электроточек риелтору вводить не нужно: они предварительно оцениваются из площади, количества комнат и санузлов. После замера эти параметры должны уточняться в полноценной смете.

Пакеты **Минимальный** и **Премиум** пока считаются по опубликованным пакетным диапазонам, потому что среди загруженных файлов нет детальных постатейных смет для этих двух пакетов.

## Запуск

```bash
npm install
npm run dev
```

Открыть: `http://localhost:8080`

## API

### GET /health

### GET /api/v1/packages

### POST /api/v1/estimate

```json
{
  "areaM2": 45.4,
  "package": "comfort",
  "propertyType": "apartment",
  "condition": "new_build",
  "bathrooms": 1,
  "rooms": 2,
  "doors": 4,
  "needsFullElectrical": true,
  "needsFullPlumbing": true,
  "needsDemolition": false,
  "needsCeiling": true,
  "hasBalcony": false,
  "warmFloorM2": 0,
  "finishLevel": 0.5
}
```

Ответ содержит итог для клиента, детализацию строк сметы, НДС, доставку, расчётные площади и отдельное вознаграждение риелтора 5%.

> Это предварительный калькулятор. Загруженные сметы сами содержат предупреждение, что стоимость может измениться после дефектовки объекта.
