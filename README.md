# Калькулятор ремонта

Калькулятор для риелтора с двумя режимами:

- **Быстрый** — площади и количество электроточек оцениваются автоматически по геометрии, откалиброванной на предоставленных сметах.
- **Точная по замерам** — риелтор вводит фактические площади и количества, после чего backend считает постатейную смету.

## Ключевое бизнес-правило

**Вознаграждение риелтора = 5% только от стоимости работ.**

В базу вознаграждения НЕ входят:
- материалы;
- доставка / разгрузка / вывоз мусора;
- НДС.

`agentReward = worksTotal × 0.05`

## Источники тарифов

Сметная модель откалибрована по предоставленным сметам сентября 2026, включая:

- ЖК Quattro, Дамбовская — 2 варианта;
- ЖК Никольский;
- ЖК Космо;
- ЖК Футуро;
- ЖК Краснооктябрьский / пакет «АРЕНДА»;
- ДОК по сторонним чертежам;
- коммерческий объект Новосёлов 92.

Из смет подтверждены, в частности:

- доставка / разгрузка / вывоз мусора = **10% от материалов**;
- НДС = **5%** от суммы до НДС;
- электрика: **1 850 ₽/м²** для минимального/арендного уровня и **1 961 ₽/м²** для актуальных Стандарт/Комфорт;
- материалы считаются коэффициентами от соответствующих блоков работ;
- двери, розетки, светильники, тёплый пол, потолок и проёмы вынесены в отдельные позиции.

## Точный режим

Дополнительно можно задать:

- черновую площадь стен;
- чистовую площадь стен;
- черновую площадь пола;
- чистовой пол;
- площадь плитки;
- площадь плитки на балконе/лоджии;
- площадь материала натяжного потолка;
- площадь монтажа натяжного потолка;
- площадь, по которой считается электрика;
- площадь демонтажа;
- количество светильников;
- количество розеток/выключателей;
- количество межкомнатных дверей;
- количество открытых дверных проёмов;
- площадь тёплого пола.

Это нужно, потому что реальные сметы показывают: площадь электрики, площадь потолка и площадь пола могут отличаться от общей площади объекта.

## Проверка по реальным сметам

Автотесты проверяют воспроизведение двух фактических смет:

- **ЖК Футуро, 45,4 м², Комфорт** → 1 930 958 ₽;
- **ЖК Краснооктябрьский, 42,2 м², минимальный/арендный уровень** → 1 006 304 ₽.

## Важно

Тип и состояние объекта сохраняются в форме, но сейчас **не умножают цену на произвольный коэффициент**. В предоставленных сметах нет подтверждённого правила вроде +5%, +10% или +15% за состояние объекта. Для вторички и нестандартных объектов корректировка должна делаться после дефектовки и фактических замеров.

## Обратная связь по ошибкам сметы

В правом блоке результата есть быстрые кнопки:

- **👍 Похоже верно** — одним кликом сохраняет положительную проверку расчёта;
- **⚠️ Есть ошибка** — открывает короткую форму: тип ошибки, ожидаемый итог и комментарий.

В Google Sheets автоматически передаются параметры объекта, пакет, итоговая стоимость, цена за м², работы, материалы, доставка, НДС, вознаграждение риелтора, выбранные опции и полный JSON расчёта.

Таблица по умолчанию: **«Ошибки по сметам»**, лист **«Лист1»**.

Для записи из backend в Google Sheets на Timeweb нужно один раз добавить секрет:

`GOOGLE_SERVICE_ACCOUNT_JSON`

Значение — полный JSON ключ сервисного аккаунта Google Cloud с полями `client_email` и `private_key`.

Альтернативно можно задать отдельно:

- `GOOGLE_CLIENT_EMAIL`
- `GOOGLE_PRIVATE_KEY`

Опционально можно переопределить:

- `FEEDBACK_SPREADSHEET_ID`
- `FEEDBACK_SHEET_NAME`

Сервисному аккаунту должен быть доступен лист для редактирования. После настройки новые отзывы записываются через `POST /api/v1/feedback`.
